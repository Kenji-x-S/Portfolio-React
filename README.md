## 📦 Getting Started Locally

### Prerequisites

- Node.js installed
- npm or yarn installed

### Installation

1. **Clone the repository:**

```bash
git clone https://github.com/Kenji-x-S/Portfolio-React.git
cd Portfolio-React
```

2. **Install dependencies:**

```bash
npm install
# or
yarn install
```

3. **Start the development server:**

```bash
npm start
# or
yarn start
```
